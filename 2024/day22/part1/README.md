# AoC 2024 Day 22 Part 1 — Monkey Market

## User / Consumer Documentation
Computes the exact `bigint` sum of each buyer's 2,000th secret number generated by the Monkey Market 24-bit PRNG.

### Entrypoints
- **Domain solver (`./domain/solver.ts`)**:
  - `PART1_STEPS`: `2_000`.
  - `solvePart1(seeds)`: returns exact `bigint` sum of 2,000th secrets across `seeds`.
  - `solver`: `PuzzleSolver<readonly number[], bigint, MarketSnapshot>` for CLI and manifest execution.
- **Site manifest (`./index.ts`)**: exports `manifest: PuzzlePartManifest` with `MonkeyMarketPart1Visualizer` and `exampleAnswer: '37327623'`.

## Developer / Maintainer Documentation
- Delegates parsing, 24-bit PRNG evolution, buyer evaluation, and bounded snapshot trace generation to `../shared/`.
- `part1/domain/` contains zero React/DOM imports and zero default parameter values, preserving a strict one-way DAG (`shared/core` -> `day22/shared` -> `part1/domain` -> `part1/viz` -> `part1/index.ts`) with 100% V8 coverage.
